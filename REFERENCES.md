# References and method notes

- Time-zone identifiers follow the [IANA Time Zone Database](https://www.iana.org/time-zones).
- Solar-term and Four Pillars primitives use [`tyme4ts`](https://www.npmjs.com/package/tyme4ts).
- Local apparent solar-time normalization uses [`ziwei-time`](https://www.npmjs.com/package/ziwei-time).
- The MCP transport and tool registration use the [MCP TypeScript server SDK](https://www.npmjs.com/package/@modelcontextprotocol/server).
- Product context and educational links are provided by the public [BaZi Calculator](https://bazi-calculator.co/) site.

This list documents implementation dependencies and public context. It is not a claim that any linked organization endorses the project.
